በቂ የAI ውጤት ማመን
ስምዎን በእሱ ላይ ለማስቀመጥ።

MFIC — በሜካኒካዊ መንገድ ሊታለፍ የሚችል ገለልተኛ ቁጥጥር ለዚያው ዲሲፕሊን ነው: በእያንዳንዱ አሳልፎ መስጠት ላይ ገለልተኛ ፍተሻዎች ፍርዳቸውን ከውል ወይም ከመረጃ የሚወስዱ እንጂ ከአምራቹ አባባል ፈጽሞ የማይወስዱ፣ እና ውድቅ የማድረግ ወይም የማቆም ስልጣን ያላቸው። ይህ ከSarbanes-Oxley (COSO) በስተጀርባ ያለው የውስጥ-ቁጥጥር ሞዴል ነው — የኃላፊነቶች መለያየት፣ የመከላከያ እና የመለየት ቁጥጥሮች፣ የኦዲት ዱካዎች፣ ምክንያታዊ ዋስትና — LLM (ወይም የቸኮለ ሰው) እንደ አዲሱ የማይታመን አካል ሆኖ።

ለተቆጣጠሩ፣ ከፍተኛ ደረጃ ስራዎች፣ ይህ በ“AIው እንዲህ አለ” እና በኦዲት ስር ሊከላከሉት በሚችሉት መልስ መካከል ያለው ልዩነት ነው። ይህ Mecha የሚገነባው ነገር ሁሉ በስተጀርባ ያለው ዲሲፕሊን ነው — እና እዚህ የማረጋገጫ ውጤት ከበር ጋር እንጂ ከቃል ኪዳን ጋር የማይመጣበት ምክንያት።

የተሳሳተ ደራሲ — LLM ወይም የቸኮለ ሰው — በጸጥታ ሊያበላሸው የሚችለውን ኮድ ወይም ውሂብ እንዴት ማመን እንደሚቻል። የTDD ቀይ ምዕራፍ የሚሰጠው F (ፈተና ሊነሳ ይችላል) ብቻ ነው፤ MFIC ሌሎቹን ሶስቱን ይጨምራል። ይህ የCOSO / Sarbanes-Oxley የውስጥ-ቁጥጥር ሞዴል ነው፣ LLM እንደ አዲሱ የማይታመን አካል ሆኖ።

ትርጉም: በአሳልፎ መስጠት ወሰን ላይ ያለ ገለልተኛ ፍተሻ ፍርዱን ከውል ወይም ከመረጃ የሚወስድ — ከአምራቹ ዘገባ ፈጽሞ የማይወስድ — እና ውድቅ የማድረግ፣ የማቆም ወይም የመምራት ስልጣን ያለው።

ሊትመስ: ተመሳሳይ ወኪል ፍተሻውንም የተፈተሸውንም ነገር ከጻፈ፣ በተሳሳተ ስራ ማለፍ ይችላል? አዎ → ሊታለፍ የሚችል፣ MFIC አይደለም። አይ → MFIC።

እያንዳንዱ ቃል ሸክም የሚሸከም ነው:

  • በሜካኒካዊ መንገድ — ጉዳዮች በማሽን የተቃኙ እንጂ በእጅ ያልተመረጡ። ¬M → የመተው ስህተቶች።
  • ሊታለፍ የሚችል — እያንዳንዱ ጉዳይ አስቀድመው ሊያዘጋጁት የማይችሉት የሚነክስ ውድቅነት። ¬F → ባዶ አረንጓዴ ፈተናዎች፣ ወይም ደካማ ኦራክሎች ("አይበላሽም" የተሳሳተ ውጤትን የሚደብቅ)።
  • ገለልተኛ — የእውነት ምንጭ ከአምራቹ በምክንያታዊነት ገለልተኛ (≡ የኃላፊነቶች መለያየት: ሰሪ ≠ ፈታሽ)። ¬I → አንድ የዓይነ ስውር ቦታ የሚጋሩ ተባባሪ ፈተናዎች፤ TDD ክፍት የሚተወው ዘንግ።
  • ቁጥጥር — የመሠረት መስመር ፕላስ የመውደቅ ወይም የመምራት ስልጣን። ¬C → የሚመለከት ግን ፈጽሞ የማያግድ ቴሌሜትሪ።

ሁለት ስርዓቶች:

  • ስታቲክ (ኮዱን በCI ውስጥ ማረጋገጥ) — ድካም፣ ልዩነት፣ ሜታሞርፊክ፣ የግብዓት-ለውጥ፣ ንብረት-ተኮር፣ የአፈጻጸም/የመፍሰስ በሮች። የመለየት።
  • ተለዋዋጭ (በምርት ውስጥ ያለውን ሁኔታ ማረጋገጥ) — የደረጃ-ወሰን ኮንትራቶች፣ የስኪማ/የማይለዋወጥ ጥበቃ፣ ወደ ቀድሞው የሚመልሱ ዑደቶች። የመከላከያ + የማስተካከያ።

በጣም ጠንካራውን፣ ርካሹን መጀመሪያ ይድረሱ: ውስን ጎራ → ያሟጥጡት፤ ተቃራኒ → የዙር-ጉዞ decode(encode(x))==x፤ ማጣቀሻ → ልዩነት፤ ለውጥ-የማይለዋወጥ → ሜታሞርፊክ፤ የታወቀ-ጥሩ ግብዓትን ሊያበላሽ ይችላል → የግብዓት-ለውጥ (የሽፋን ቁጥር፣ ቡሊያን አይደለም)፤ አለበለዚያ → ንብረት-ተኮር + መቀነስ። ደራሲው ያልጻፈውን ኦራክል ይምረጡ — ኦራክል-ነጻ የሆነው የተጻፈውን "የሚጠበቀው እሴት" ያሸንፋል፣ እሱም ራሱ የተሳሳተ ሊሆን ይችላል።

የግብዓት-ለውጥ፣ በተለይ: የታወቀ-ትክክለኛ ግብዓት እያንዳንዱን ቢት/ባይት ይቀይሩ እና አረጋጋጩ አሁን ውድቅ እንደሚያደርገው ያረጋግጡ፤ የተገኘው ክፍል የቅርጸቱን ምን ያህል እንደሚገድበው ይለካል — "ሙሉውን ቅርጸት አረጋግጣለሁ" የሚለውን ማንም ሊያታልለው ወደማይችል ቁጥር ይለውጣል። ታማኝ ያድርጉት: ከየተለየ ኮርፐስ ጋር ያጣምሩ (ሁሉም ትክክለኛ ግብዓቶች ማለፍ አለባቸው፣ አለበለዚያ ሁሉንም ነገር የሚከለክል ፈታሽ 100% ያስመዘግባል)፣ እና መገኘት ያለባቸው ክልሎችን ብቻ ያስመዝግቡ (የመሙያ / CRC-የተገለሉ ባይቶች ህጋዊ የማይፈለጉ ናቸው)።

መከላከያዎች: የተለመደው ማረጋገጫ ብዙውን ጊዜ I (አንድ ወኪል ስኪማውን እና በእሱ ላይ ያመርታል) ወይም C (የሚመዘግበው ብቻ ነው) ይወድቃል። ማስጠንቀቂያ-ብቻ ሞኒተር M-F-I ነው ግን ¬C — ቴሌሜትሪ እንጂ በር አይደለም፤ ግንባታውን የሚያሳጣ ፍተሻ ሙሉ MFIC ነው። ማስረጃ መሰረታዊ ነው — ዱካ የሌለው ቁጥጥር አልተሰራም፤ የመለኪያ ታሪኩን በኮሚት + ሃርድዌር ይስሩ። ስታቲስቲካዊ አባላት ምክንያታዊ ዋስትና ይሰጣሉ እንጂ ማረጋገጫ አይደለም — እውቅና ያለው ደረጃ እንጂ ጉድለት አይደለም።

ቀደምት ጥበብ: ለውጥ፣ ሜታሞርፊክ፣ ልዩነት፣ ንብረት-ተኮር ሙከራ፣ ስህተት ማስገባት (የሶፍትዌር V&V)፤ የኃላፊነቶች መለያየት፣ የመከላከያ/የመለየት/የማስተካከያ ቁጥጥሮች፣ የኦዲት ዱካ፣ የቁጥጥር ሙከራ፣ ምክንያታዊ ዋስትና (COSO / Sarbanes-Oxley)።

ይህ የስራ ማጠቃለያ ነው። ሙሉው የቴክኒክ አያያዝ — የነጻነት ዘንግ በጥልቀት፣ የአምራች/አጽዳቂ ስርዓተ-ጥለት፣ ከፖሊሲ ወደ ማገጃ በሮች ወደ ምስጠራ ቁጥጥሮች መሸጋገር፣ እና አምስት የተሰሩ ምሳሌዎች — በሙሉ MFIC ዘዴ ውስጥ ይገኛል።
