MFIC — ការត្រួតពិនិត្យឯករាជ្យដែលអាចក្លែងបន្លំដោយមេកានិច គឺជាវិន័យសម្រាប់រឿងនោះ៖ ការត្រួតពិនិត្យឯករាជ្យនៅគ្រប់ការប្រគល់ដែលទទួលបានការវិនិច្ឆ័យរបស់ពួកគេពីកិច្ចសន្យា ឬទិន្នន័យ មិនមែនមកពីការនិយាយរបស់ផលិតករនោះទេ ហើយមានសិទ្ធិអំណាចក្នុងការបដិសេធ ឬបញ្ឈប់។ វាគឺជាគំរូនៃការត្រួតពិនិត្យផ្ទៃក្នុងនៅពីក្រោយ Sarbanes-Oxley (COSO) — ការបែងចែកភារកិច្ច ការត្រួតពិនិត្យបង្ការ និងរកឃើញ ផ្លូវសវនកម្ម ការធានាសមហេតុផល — ជាមួយនឹង LLM (ឬមនុស្សប្រញាប់) ជាភាគីដែលមិនគួរទុកចិត្តថ្មី។

សម្រាប់ការងារដែលមានហានិភ័យខ្ពស់ដែលត្រូវបានគ្រប់គ្រង នោះគឺជាភាពខុសគ្នារវាង “AI បាននិយាយដូច្នេះ” និងចម្លើយដែលអ្នកអាចការពារក្រោមការធ្វើសវនកម្ម។ វាគឺជាវិន័យនៅពីក្រោយអ្វីគ្រប់យ៉ាងដែល Mecha បង្កើត — និងហេតុផលដែលលទ្ធផលផ្ទៀងផ្ទាត់នៅទីនេះមកជាមួយច្រកទ្វារ មិនមែនការសន្យានោះទេ។

របៀបជឿទុកចិត្តលើកូដ ឬទិន្នន័យដែលអ្នកនិពន្ធដែលងាយនឹងខុស — LLM ឬមនុស្សប្រញាប់ — អាចបំផ្លាញដោយស្ងៀមស្ងាត់។ ដំណាក់កាលក្រហមរបស់ TDD ផ្តល់តែ F (ការធ្វើតេស្ត អាច បាញ់); MFIC បន្ថែមបីផ្សេងទៀត។ វាគឺជាគំរូនៃការត្រួតពិនិត្យផ្ទៃក្នុង COSO / Sarbanes-Oxley ជាមួយនឹង LLM ជាភាគីដែលមិនគួរទុកចិត្តថ្មី។

និយមន័យ៖ ការត្រួតពិនិត្យឯករាជ្យនៅ ព្រំដែនប្រគល់ ដែលទទួលបានការវិនិច្ឆ័យរបស់វាពីកិច្ចសន្យា ឬទិន្នន័យ — មិនមែនមកពីគណនីរបស់អ្នកផលិតនោះទេ — ហើយមានសិទ្ធិអំណាចក្នុងការ បដិសេធ បញ្ឈប់ ឬដឹកនាំ។

លីតមូស៖ ប្រសិនបើភ្នាក់ងារដូចគ្នាបានសរសេរទាំងការត្រួតពិនិត្យ និងអ្វីដែលបានត្រួតពិនិត្យ តើវាអាចឆ្លងកាត់ដោយការងារខុសដែរឬទេ? បាទ → អាចលេងបាន មិនមែន MFIC។ ទេ → MFIC។

ពាក្យនីមួយៗមានបន្ទុក៖

  • ដោយមេកានិច — ករណីដែលម៉ាស៊ីនបានបោសសម្អាត មិនមែន ជ្រើសរើសដោយដៃទេ។ ¬M → កំហុសក្នុងការលុបចោល។
  • អាចក្លែងបន្លំបាន — ករណីនីមួយៗគឺជាការបដិសេធយ៉ាងខ្លាំងដែលអ្នក មិនអាចរៀបចំទុកជាមុនបាន។ ¬F → ការធ្វើតេស្តពណ៌បៃតងទទេ ឬ oracle ខ្សោយ ("មិន គាំង" លាក់លទ្ធផលខុស)។
  • ឯករាជ្យ — ប្រភពការពិតដែលមិនពាក់ព័ន្ធនឹង អ្នកផលិត (≡ ការបែងចែកភារកិច្ច: អ្នកបង្កើត ≠ អ្នកត្រួតពិនិត្យ)។ ¬I → ការធ្វើតេស្តរួមគ្នាដែលចែករំលែកចំណុចខ្វះខាតមួយ; អ័ក្ស TDD ទុកចោល។
  • ការត្រួតពិនិត្យ — គោលបំណង បូក សិទ្ធិអំណាចក្នុងការបរាជ័យ ឬដឹកនាំ។ ¬C → ទូរមាត្រដែលសង្កេតប៉ុន្តែមិនដែល រារាំង។

របបពីរ៖

  • ឋិតិវន្ត (ផ្ទៀងផ្ទាត់កូដ នៅក្នុង CI) — ការអស់កម្លាំង ភាពខុសគ្នា ការផ្លាស់ប្តូរ ការផ្លាស់ប្តូរធាតុចូល ផ្អែកលើលក្ខណសម្បត្តិ ច្រកទ្វារ perf/leak ។ អ្នកស៊ើបអង្កេត។
  • ថាមវន្ត (ផ្ទៀងផ្ទាត់ស្ថានភាពកំពុងដំណើរការ នៅក្នុងផលិតកម្ម) — កិច្ចសន្យាព្រំដែនដំណាក់កាល ការរក្សាសេម៉ា/អថេរ ការបដិសេធទៅកាន់រង្វិលជុំមុន។ បង្ការ + កែតម្រូវ។

ឈានដល់កម្លាំងខ្លាំងបំផុត ថោកបំផុតជាមុន៖ ដែនកំណត់មានកំណត់ → អស់វា; ច្រាស → ជុំវិញ decode(encode(x))==x; ឯកសារយោង → ភាពខុសគ្នា; ការផ្លាស់ប្តូរអថេរ → ការផ្លាស់ប្តូរ; អាចបំផ្លាញធាតុចូលដែលគេស្គាល់ល្អ → ការផ្លាស់ប្តូរធាតុចូល (លេខ គ្របដណ្តប់ មិនមែន bool); ផ្សេងទៀត → ផ្អែកលើលក្ខណសម្បត្តិ + បង្រួម។ ចូលចិត្ត oracle ដែលអ្នកនិពន្ធមិនបាន សរសេរ — oracle-free ឈ្នះលើ "តម្លៃរំពឹងទុក" ដែលបានសរសេរដែល អាចខុសដោយខ្លួនឯង។

ការផ្លាស់ប្តូរធាតុចូល ជាពិសេស៖ ប្តូររាល់ប៊ីត/បៃត៍នៃ ធាតុចូលដែលគេស្គាល់ថាត្រឹមត្រូវ ហើយបញ្ជាក់ថាអ្នកផ្ទៀងផ្ទាត់ឥឡូវនេះ បដិសេធ វា; ប្រភាគដែលបានរកឃើញវាស់វែងថាតើទម្រង់ប៉ុន្មានដែលវាពិតជាកំណត់ — បង្វែរ "ខ្ញុំផ្ទៀងផ្ទាត់ទម្រង់ទាំងមូល" ទៅជាលេខដែលគ្មាននរណាម្នាក់អាច បំភាន់បាន។ រក្សាវាឱ្យស្មោះត្រង់៖ ផ្គូផ្គងជាមួយ corpus ជាក់លាក់ (ធាតុចូលត្រឹមត្រូវទាំងអស់ត្រូវតែឆ្លងកាត់ បើមិនដូច្នេះទេអ្នកត្រួតពិនិត្យបដិសេធអ្វីៗទាំងអស់ ទទួលបាន 100%) ហើយដាក់ពិន្ទុតែ តំបន់ដែលត្រូវរកឃើញ (ការបំពេញ / បៃត៍ដែលមិនរាប់បញ្ចូល CRC គឺជាការមិនខ្វល់ខ្វាយស្របច្បាប់)។

របាំងការពារ៖ ការផ្ទៀងផ្ទាត់ធម្មតាជាធម្មតាបរាជ័យ I (ភ្នាក់ងារមួយកំណត់គ្រោងការណ៍ និង ផលិតប្រឆាំងនឹងវា) ឬ C (វាគ្រាន់តែចូល)។ ម៉ូនីទ័រព្រមានតែប៉ុណ្ណោះគឺ M-F-I ប៉ុន្តែ ¬C — ទូរមាត្រ មិនមែនច្រកទ្វារ; ការត្រួតពិនិត្យដែល បរាជ័យក្នុងការបង្កើត គឺពេញ MFIC។ ភស្តុតាងគឺជា ធាតុផ្សំ — ការត្រួតពិនិត្យដែលគ្មានផ្លូវមិនបានដំណើរការ; កំណែប្រវត្តិវាស់វែងរបស់វាដោយ commit + ផ្នែករឹង។ សមាជិកស្ថិតិផ្តល់ ការធានាសមហេតុផល មិនមែនភស្តុតាង — ស្តង់ដារដែលទទួលស្គាល់ មិនមែន កង្វះខាតនោះទេ។

សិល្បៈពីមុន៖ ការផ្លាស់ប្តូរ ការផ្លាស់ប្តូរ ការបែងចែក ការធ្វើតេស្តផ្អែកលើលក្ខណសម្បត្តិ ការចាក់បញ្ចូលកំហុស (software V&V); ការបែងចែក ភារកិច្ច ការត្រួតពិនិត្យបង្ការ/រកឃើញ/កែតម្រូវ ផ្លូវសវនកម្ម ការធ្វើតេស្ត ការត្រួតពិនិត្យ ការធានាសមហេតុផល (COSO / Sarbanes-Oxley)។

នេះគឺជាសេចក្តីសង្ខេបការងារ។ ការព្យាបាលបច្ចេកទេសពេញលេញ — អ័ក្សឯករាជ្យស៊ីជម្រៅ លំនាំអ្នកផលិត/អ្នកអនុម័ត ការកើនឡើងពីគោលនយោបាយទៅច្រកទ្វាររារាំងទៅការត្រួតពិនិត្យគ្រីបតូក្រាហ្វិក និងឧទាហរណ៍ការងារប្រាំ — មាននៅក្នុង វិធីសាស្ត្រ MFIC ពេញលេញ។
